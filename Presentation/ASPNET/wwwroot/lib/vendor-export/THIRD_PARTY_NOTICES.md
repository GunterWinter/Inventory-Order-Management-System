# Export/import browser libraries

- SheetJS Community Edition 0.18.5 (`xlsx.full.min.js`) — Apache-2.0.
- html2canvas 1.4.1 (`html2canvas.min.js`) — MIT.
- jsPDF 2.5.1 (`jspdf.umd.min.js`) — MIT.

The files are vendored at pinned versions so workbook and PDF features do not
depend on a public CDN at runtime. Upstream license banners remain in the
minified distributions.
